# Magic Door

A magic door. Open it and it takes you to a website: the NeoForge website.
When you open the door, purple sparkles fly out, you hear a teleport sound, and
Minecraft asks if you want to open the link. Say yes and your web browser goes
there.

Craft it from an oak door and an ender pearl.

Made by Elduin. Fabric, Minecraft 1.21.11 and 26.2.
